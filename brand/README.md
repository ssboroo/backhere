# BackHere brand

The folded bookmark holds your place; the returning arrow leads you back to it.

- Evergreen: `#326C4B`
- Dark ink: `#202D25`
- Paper: `#F4F6F5`
- Dark surface: `#131A17`
- Light accent on dark: `#A3DBB4`
- UI type: Segoe UI; web fallback: system-ui, Arial, sans-serif.

Use the mark at 16 px or larger. Leave at least a quarter of the mark's width as clear space. Do not stretch, rotate, add a glow or change individual parts. Prefer SVG for web and the generated multi-size ICO for Windows. Wordmark is written exactly `BackHere`.

Source of truth for raster/ICO rendering: `desktop/brand.py`. SVG follows the same 128 × 128 geometry. `scripts/make-icon.py` produces the Windows icon, transparent PNGs and a complete brand kit ZIP.
