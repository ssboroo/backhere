# BackHere Browser Companion 0.5.1
For Chromium browsers (Chrome, Edge, Brave, Vivaldi, Opera). No server, account or host permission.

1. Extract this ZIP to a permanent folder.
2. Open your browser's Extensions management page, enable Developer mode, choose **Load unpacked**, and select the extracted folder containing manifest.json.
3. Pin BackHere, click it, choose the correct browser, and **Save browser workspace**.
4. In BackHere desktop, capture a workspace while that browser is open, select the workspace, and choose **Import browser tabs** with the saved JSON.
5. Alternatively, choose the JSON inside this extension and explicitly open its tabs in new windows. This also restores pinned/active tabs.

Only HTTP/HTTPS URLs are saved (up to 64 windows / 200 tabs per window). Private windows, internal pages, browser history, cookies, passwords, page forms and unsaved contents are excluded. Export files contain browsing URLs/titles in plain text: store them privately. Desktop restore opens tab URLs; use the extension to restore pinned/active tab flags. Existing browser windows are preserved, so restoring repeatedly can create duplicates. Browser security restrictions may prevent some pages loading. Firefox is not supported by this companion.
