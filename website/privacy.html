The Windows app

BackHere stores your notes, file paths, URLs, project names and preferences in your Windows user profile, under %LOCALAPPDATA%\BackHere. The app does not send note contents to Rainy Studio, does not require an account and does not include app analytics or cloud synchronization.

The local database, JSON exports and recovery snapshots are not encrypted. Anyone with access to your Windows profile or backup files may be able to read them. Daily snapshots are kept locally for seven dates. Before restoring a snapshot, the current notes are exported to a separate local JSON file.

Capture and opening links

When you use the capture shortcut, BackHere reads the foreground window title and attempts to read a supported file selection, browser address bar or Word/Excel window. This happens locally. It does not record general keyboard activity or read or replace your clipboard.

Opening a saved web URL uses your default browser and contacts that website. File links open their associated Windows application. Manual links to GitHub downloads, source code and support contact GitHub and are covered by GitHub’s own privacy practices.

This website

This website stores your selected interface language in localStorage. It does not contain advertising, analytics scripts, account creation or a payment form. Its hosting and download providers may process ordinary connection information, such as your IP address, browser and requested resources, to serve the site and files.

Deletion, backups and support

You can delete completed notes in the app. Previously exported files and recovery snapshots remain until you remove them. Uninstalling BackHere leaves the application data folder in place so you do not lose your work. To remove all local data, fully exit BackHere and remove its data folder and any exported backups yourself.

Support is available through GitHub Issues. Do not post passwords, private documents, access tokens or sensitive note contents in a public issue.
